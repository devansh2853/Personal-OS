# 3.2 Functional Requirements — User Profile

---

# 3.2.1 Purpose

The User Profile module is responsible for managing a user's personal information, fitness preferences, measurement units, goals, and application settings.

This module provides the foundational user data required by multiple domains such as Nutrition, Weight Tracking, Workout Tracking, Analytics, Notifications, and AI Personal Trainer.

---

# 3.2.2 Scope

This module includes:

- Personal Information
- Fitness Information
- Measurement Preferences
- Daily Goals
- Notification Preferences
- Account Preferences

This module does not include:

- Authentication
- Weight Logs
- Workout Logs
- Meal Logs
- Supplement Logs
- Analytics

---

# 3.2.3 Business Rules

### BR-PROFILE-001

Each authenticated user shall have exactly one profile.

---

### BR-PROFILE-002

A profile belongs to exactly one user account.

---

### BR-PROFILE-003

Profile information may be updated at any time by its owner.

---

### BR-PROFILE-004

Measurement units shall be applied consistently throughout the application.

---

### BR-PROFILE-005

Changes to profile preferences shall immediately affect future calculations where applicable.

---

# 3.2.4 Functional Requirements

## Profile Creation

### FR-PROFILE-001

The system shall automatically create a profile when a new user account is created.

---

### FR-PROFILE-002

The system shall associate each profile with exactly one user.

---

## Personal Information

### FR-PROFILE-003

The system shall allow users to view their profile information.

---

### FR-PROFILE-004

The system shall allow users to edit their display name.

---

### FR-PROFILE-005

The system shall allow users to upload or change a profile picture.

---

### FR-PROFILE-006

The system shall allow users to specify their date of birth.

---

### FR-PROFILE-007

The system shall allow users to specify their biological sex.

---

### FR-PROFILE-008

The system shall allow users to specify their height.

---

## Measurement Preferences

### FR-PROFILE-009

The system shall allow users to select their preferred weight unit.

Examples:

- Kilograms (kg)
- Pounds (lb)

---

### FR-PROFILE-010

The system shall allow users to select their preferred height unit.

Examples:

- Centimeters (cm)
- Feet & Inches (ft/in)

---

### FR-PROFILE-011

The system shall display values using the user's preferred units.

---

### FR-PROFILE-012

The system shall preserve stored measurements independently of the selected display unit.

---

## Daily Goals

### FR-PROFILE-013

The system shall allow users to configure a daily calorie goal.

---

### FR-PROFILE-014

The system shall allow users to configure a daily protein goal.

---

### FR-PROFILE-015

The system shall allow users to configure daily carbohydrate goals.

---

### FR-PROFILE-016

The system shall allow users to configure daily fat goals.

---

### FR-PROFILE-017

The system shall allow users to configure a daily water intake goal.

---

### FR-PROFILE-018

The system shall allow users to update these goals at any time.

---

## Fitness Preferences

### FR-PROFILE-019

The system shall allow users to specify their primary fitness objective.

Examples include:

- Lose Weight
- Maintain Weight
- Gain Muscle
- Improve Strength
- Improve General Fitness

---

### FR-PROFILE-020

The system shall allow users to specify their activity level.

---

### FR-PROFILE-021

The system shall allow users to specify their training experience.

---

## Notification Preferences

### FR-PROFILE-022

The system shall allow users to enable or disable notifications.

---

### FR-PROFILE-023

The system shall allow users to configure reminder times.

---

### FR-PROFILE-024

The system shall allow users to configure notification preferences independently for each reminder category.

Examples:

- Water
- Supplements
- Workouts

---

## AI Preferences

### FR-PROFILE-025

The system shall allow users to enable or disable AI-powered features.

---

### FR-PROFILE-026

The system shall continue functioning normally when AI features are disabled.

---

## Data Management

### FR-PROFILE-027

The system shall allow users to export their personal data.

---

### FR-PROFILE-028

The system shall allow users to request deletion of all personal data through account deletion.

---

## Security

### FR-PROFILE-029

The system shall allow only the profile owner to modify profile information.

---

### FR-PROFILE-030

The system shall prevent users from accessing another user's profile.

---

# 3.2.5 Acceptance Criteria

The User Profile module shall be considered complete when:

- A profile is automatically created for every new user.
- Users can update personal information.
- Users can configure preferred units.
- Users can configure nutrition goals.
- Users can configure water goals.
- Users can configure notification preferences.
- AI can be enabled or disabled independently.
- Profile data is accessible only by its owner.

---

# 3.2.6 Edge Cases

The system shall correctly handle:

- Missing optional profile information.
- Invalid height values.
- Invalid date of birth.
- Switching measurement units.
- Extremely high or low goal values.
- Uploading unsupported profile image formats.
- Unauthorized profile access attempts.

---

# 3.2.7 Out of Scope

The following features are outside the scope of Phase 1:

- Multiple profiles per account.
- Family profile management.
- Coach or trainer-managed profiles.
- Public user profiles.
- Social features.
- Friend lists.
- Profile sharing.

---

# 3.2.8 Future Enhancements

Potential future improvements include:

- Profile completion score.
- Progress photos.
- Body measurements (waist, chest, arms, thighs, etc.).
- Medical conditions.
- Dietary preferences.
- Allergies.
- Fitness coach assignment.
- Family account support.
- Public profile sharing.
- Connected wearable devices.
