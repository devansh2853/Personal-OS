# 3.4.1 Functional Requirements — Workout Templates

---

# 3.4.1.1 Purpose

The Workout Templates module enables users to create, organize, and manage reusable workout plans.

Workout templates define the planned structure of a workout, including the exercises, their order, target sets, repetitions, rest periods, and optional notes. Templates act as blueprints and are never modified by workout execution unless the user explicitly chooses to update them.

---

# 3.4.1.2 Scope

This module includes:

- Workout Template Management
- Template Organization
- Exercise Management within Templates
- Exercise Ordering
- Exercise Configuration
- Template Validation

This module does not include:

- Workout Execution
- Workout Sessions
- Set Logging
- Workout History
- Personal Records

---

# 3.4.1.3 Business Rules

### BR-WT-T-001

Each workout template shall belong to exactly one user.

---

### BR-WT-T-002

A user may create multiple workout templates.

---

### BR-WT-T-003

Each workout template shall have a unique identifier.

---

### BR-WT-T-004

Template names are not required to be unique.

Example:

- Push Day
- Push Day
- Push Day (Gym)

All are valid.

---

### BR-WT-T-005

A workout template shall contain at least one exercise before it can be used to start a workout session.

---

### BR-WT-T-006

A workout template references exercises from the Exercise Library.

---

### BR-WT-T-007

Removing an exercise from the Exercise Library shall not delete historical workout templates or sessions.

---

### BR-WT-T-008

Editing a workout template shall not modify completed workout sessions.

---

### BR-WT-T-009

Workout templates act as reusable blueprints.

---

### BR-WT-T-010

Changes made during an active workout session shall not modify the originating template unless the user explicitly chooses to update the template.

---

# 3.4.1.4 Functional Requirements

## Template Management

### FR-WT-T-001

The system shall allow authenticated users to create workout templates.

---

### FR-WT-T-002

The system shall allow users to rename workout templates.

---

### FR-WT-T-003

The system shall allow users to delete workout templates.

---

### FR-WT-T-004

The system shall require confirmation before permanently deleting a workout template.

---

### FR-WT-T-005

Deleting a workout template shall not delete historical workout sessions created from that template.

---

### FR-WT-T-006

The system shall allow users to duplicate existing workout templates.

---

### FR-WT-T-007

Duplicated templates shall receive a new unique identifier.

---

### FR-WT-T-008

Duplicated templates shall copy all exercises and exercise configurations.

---

## Template Listing

### FR-WT-T-009

The system shall display all workout templates belonging to the authenticated user.

---

### FR-WT-T-010

The system shall display the template name.

---

### FR-WT-T-011

The system shall display the number of exercises contained within each template.

---

### FR-WT-T-012

The system shall display the last modified date of each template.

---

## Exercise Management

### FR-WT-T-013

The system shall allow users to add exercises from the Exercise Library.

---

### FR-WT-T-014

The system shall prevent adding exercises that do not exist in the Exercise Library.

---

### FR-WT-T-015

The system shall allow the same exercise to appear multiple times within a template.

Example:

Romanian Deadlift

...

Romanian Deadlift (Finisher)

---

### FR-WT-T-016

Each exercise instance shall maintain its own independent configuration.

---

### FR-WT-T-017

The system shall allow users to remove exercises from a template.

---

### FR-WT-T-018

Removing an exercise shall not delete the exercise from the Exercise Library.

---

## Exercise Ordering

### FR-WT-T-019

The system shall maintain the order of exercises within a workout template.

---

### FR-WT-T-020

The system shall allow users to reorder exercises.

---

### FR-WT-T-021

Exercise order shall be preserved when the workout template is used to create a workout session.

---

## Exercise Configuration

### FR-WT-T-022

The system shall allow users to configure the target number of sets for each exercise.

---

### FR-WT-T-023

The system shall allow users to configure the target repetitions for each set.

---

### FR-WT-T-024

The system shall allow users to configure a default rest duration for each exercise.

---

### FR-WT-T-025

The system shall allow users to attach notes to each exercise.

Example:

- Pause at the bottom
- Slow eccentric
- Use lifting straps

---

### FR-WT-T-026

Exercise notes shall be visible during workout sessions.

---

### FR-WT-T-027

The system may allow users to define an optional default working weight.

---

## Template Notes

### FR-WT-T-028

The system shall allow users to attach notes to the workout template.

Example:

Focus on chest contraction.

---

### FR-WT-T-029

Template notes shall be available during workout sessions.

---

## Validation

### FR-WT-T-030

The system shall prevent starting a workout from an empty template.

---

### FR-WT-T-031

The system shall validate that every exercise reference exists.

---

### FR-WT-T-032

The system shall preserve template integrity after edits.

---

## Future Compatibility

### FR-WT-T-033

The system architecture shall support supersets in future releases.

---

### FR-WT-T-034

The system architecture shall support drop sets in future releases.

---

### FR-WT-T-035

The system architecture shall support circuit training in future releases.

---

### FR-WT-T-036

The system architecture shall support exercise grouping in future releases.

---

### FR-WT-T-037

The system architecture shall support workout template sharing in future releases.

---

### FR-WT-T-038

The system architecture shall support public workout templates in future releases.

---

# 3.4.1.5 Acceptance Criteria

The Workout Templates module shall be considered complete when:

- Users can create workout templates.
- Users can edit workout templates.
- Users can duplicate workout templates.
- Users can delete workout templates.
- Users can add exercises.
- Users can remove exercises.
- Users can reorder exercises.
- Users can configure exercise settings.
- Users can attach notes.
- Workout templates can be used to start workout sessions.

---

# 3.4.1.6 Edge Cases

The system shall correctly handle:

- Creating a template without a name.
- Creating an empty template.
- Attempting to start a workout from an empty template.
- Deleting templates with historical workout sessions.
- Duplicate exercise entries.
- Invalid exercise references.
- Simultaneous edits from multiple devices.
- Exercises removed or deprecated from future Exercise Library updates.

---

# 3.4.1.7 Out of Scope

The following features are outside Phase 1:

- Public template marketplace.
- Community templates.
- Collaborative editing.
- AI-generated workout templates.
- Coach-created templates.
- Version history for templates.
- Folder organization for templates.
