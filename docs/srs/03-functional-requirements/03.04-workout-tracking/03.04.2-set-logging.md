# 3.4.3 Functional Requirements — Set Logging

---

# 3.4.3.1 Purpose

The Set Logging module enables users to record the details of each exercise performed during a workout session.

Each logged set represents a single attempt of an exercise and records performance metrics such as weight, repetitions, completion status, and optional notes.

Set logging provides the foundation for workout history, progression tracking, personal records, analytics, and future AI recommendations.

---

# 3.4.3.2 Scope

This module includes:

- Exercise Sessions
- Set Management
- Set Configuration
- Rest Timer
- Exercise Completion
- Workout Completion

This module does not include:

- Workout Templates
- Workout History
- Personal Records
- Analytics

---

# 3.4.3.3 Business Rules

### BR-WT-L-001

Every logged set shall belong to exactly one Exercise Session.

---

### BR-WT-L-002

Each set shall have a unique identifier.

---

### BR-WT-L-003

Sets are recorded in chronological order.

---

### BR-WT-L-004

Users may modify sets until the workout session is completed.

---

### BR-WT-L-005

Completed workout sessions become read-only.

---

### BR-WT-L-006

Deleting a set affects only the current workout session.

---

# 3.4.3.4 Functional Requirements

## Exercise Session

### FR-WT-L-001

The system shall create an Exercise Session for every exercise in the workout session.

---

### FR-WT-L-002

Each Exercise Session shall reference an Exercise from the Exercise Library.

---

### FR-WT-L-003

Exercise Sessions shall maintain their own independent state.

---

### FR-WT-L-004

Exercise Sessions shall maintain their display order.

---

### FR-WT-L-005

Users shall be able to mark an exercise as completed.

---

### FR-WT-L-006

Users shall be able to reopen an exercise until the workout session is completed.

---

## Set Management

### FR-WT-L-007

The system shall allow users to add sets.

---

### FR-WT-L-008

The system shall allow users to edit sets.

---

### FR-WT-L-009

The system shall allow users to delete sets.

---

### FR-WT-L-010

The system shall allow users to duplicate a previously logged set.

---

### FR-WT-L-011

The system shall allow users to reorder sets.

---

## Set Details

### FR-WT-L-012

Each set shall record weight.

---

### FR-WT-L-013

Each set shall record repetitions.

---

### FR-WT-L-014

Users may optionally record the duration of time-based exercises.

Examples:

- Plank
- Wall Sit

---

### FR-WT-L-015

Users may optionally attach notes to a set.

---

### FR-WT-L-016

The system shall record whether a set has been completed.

---

### FR-WT-L-017

The system shall display measurement units according to the user's preferences.

Examples:

- kg
- lb

---

## Previous Performance

### FR-WT-L-018

The system shall display the previous workout's performance for the current exercise.

---

### FR-WT-L-019

Previous performance shall include:

- Weight
- Repetitions
- Number of sets

---

### FR-WT-L-020

The system may pre-fill set values using the previous workout.

---

## Rest Timer

### FR-WT-L-021

The system shall allow users to start a rest timer.

---

### FR-WT-L-022

The system shall automatically start the default rest timer after a completed set when enabled.

---

### FR-WT-L-023

Users shall be able to skip the rest timer.

---

### FR-WT-L-024

Users shall be able to stop the rest timer early.

---

### FR-WT-L-025

Users shall be able to change the remaining rest duration.

---

### FR-WT-L-026

The system shall notify users when the rest timer completes.

---

## Exercise Completion

### FR-WT-L-027

Users shall be able to complete an exercise regardless of whether all planned sets were performed.

---

### FR-WT-L-028

The system shall distinguish between planned sets and completed sets.

---

### FR-WT-L-029

The system shall allow users to add additional sets beyond the planned number.

---

### FR-WT-L-030

Additional sets shall be included in workout history and analytics.

---

## Validation

### FR-WT-L-031

Weight values shall be zero or greater.

---

### FR-WT-L-032

Repetition values shall be greater than zero.

---

### FR-WT-L-033

Duration values shall be greater than zero.

---

### FR-WT-L-034

The system shall prevent saving invalid set data.

---

## Auto Save

### FR-WT-L-035

The system shall automatically save set changes immediately after they are made.

---

### FR-WT-L-036

The system shall recover unsynchronized set data after unexpected application termination.

---

# 3.4.3.5 Acceptance Criteria

The Set Logging module shall be considered complete when:

- Users can log sets.
- Users can edit sets.
- Users can delete sets.
- Users can log weight and repetitions.
- Users can log time-based exercises.
- Previous workout values are displayed.
- Rest timer functions correctly.
- Additional sets can be added.
- Exercise completion is tracked.
- Workout progress is automatically saved.

---

# 3.4.3.6 Edge Cases

The system shall correctly handle:

- Zero-weight exercises.
- Bodyweight exercises.
- Time-based exercises.
- Additional unplanned sets.
- Deleting the final set of an exercise.
- Completing an exercise with no logged sets.
- Editing sets after reconnecting from offline mode.
- Interrupted rest timers.

---

# 3.4.3.7 Out of Scope

The following features are outside Phase 1:

- Velocity-based training.
- Bar path analysis.
- Automatic rep counting.
- Wearable sensor integration.
- Camera-based form detection.
- AI form analysis.

---

Potential future improvements include:

- Automatic weight progression.
- Fatigue tracking.
- Adaptive rest periods.
- AI-generated weight recommendations.
- Voice-controlled logging.
- Smartwatch set detection.
